## ✨ Key Features

- 잉크총을 쏘면 [ 검정, 노랑, 파랑, 빨강 ] 잉크에 따라 능력을 발휘할 수 있다.
    - [파랑] - 바닥의 잉크에 닿으면 슈퍼점프
    - [검정] - 몬스터 공격
    - [노랑] - 벽의 잉크에 닿으면 벽타기
    - [빨강] - 천장의 잉크에 닿으면 천장 걷기
